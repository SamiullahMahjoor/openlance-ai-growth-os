# Open Lance Color Standard

This document owns the Color standard for Open Lance: the roles color plays, the intent behind them, and the accessibility they must meet. It is a brand standard document within the Brand namespace, and it follows the Brand Document Standard defined in knowledge/brand/README.md. This document owns the standard only. The specific encoded color values, the color space, the design tokens, and the rendering of color are owned by the codebase and the design system. Where this document and a higher-authority document differ, the higher-authority document governs.

# Purpose

This document owns the standard for how Open Lance uses color. Its purpose is that color always carries the same meaning and the same feeling, and is always accessible, whoever or whatever applies it and whatever the medium.

# Standard

Open Lance uses color by the following durable rules, stated by role and intent rather than by value.

- Primary color. The brand's primary color is a warm amber. It carries the brand's energy and optimism and owns emphasis: primary actions, key highlights, and the brand mark. It is used with intent and sparingly, so that it keeps its weight, and never as a flooding wash.
- Secondary accent. A cool teal is the secondary accent. It is used sparingly for secondary actions, links, and data, gives the warm palette a calm counterpoint, and never competes with or substitutes for the primary.
- Neutrals. A warm-tinted neutral range provides calm, legible backgrounds, surfaces, and text. Neutrals do the quiet work of the interface so the primary can provide the accent.
- Semantic colors. Distinct, conventional colors carry success, warning, error, and information. A semantic color is used only for its meaning, never for decoration, and its meaning is the same everywhere it appears.
- Accessibility. Every color pairing meets at least the accepted contrast standard for its use, with the recognized AA level as the floor for text and essential interface elements. Color is never the only carrier of meaning; it is always paired with text, shape, or icon.
- Light and dark. The identity holds in both light and dark presentation. The roles above stay the same; only the rendered values adapt.
- Restraint. The palette is small and disciplined. Colors are not added casually, and the primary earns attention precisely because it is used with restraint.

# Rationale

Color is felt before it is read, so it must feel like the organization. A warm amber expresses the approachable, optimistic, human character the brand commits to, while a restrained cool accent and calm neutrals keep the experience trustworthy and uncluttered, which matters in a marketplace where money and trust are at stake, owned by knowledge/company/mission.md. Making accessibility a floor rather than an afterthought expresses the fairness and inclusion the organization holds as principles, owned by knowledge/company/principles.md: a color system everyone can use is part of a fair marketplace.

# Application

The color standard applies wherever the brand appears, in every medium: screens in light and dark, print, presentations, and social. When applying color, a contributor or agent uses each color for its stated role, checks that every pairing meets the contrast floor, and never leans on color alone to signal meaning. This document states the standard by role and intent; the encoded values, tokens, and rendering that realize it are owned by the codebase and design system, and it never itself produces an Output.
