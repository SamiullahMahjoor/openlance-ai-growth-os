## Ownership and constitutional responsibility

This package reserves the `ai/evolution/` namespace, whose constitutional responsibility is the constitutional architecture describing how the AI layer itself evolves, and its structural integration with the knowledge repository. It owns none of that behavior here; the frozen constitution (OL-AI-EVOLUTION-README) owns it, and this package only reserves the name and the dependency edges so the package map is explicit and future conflicts are prevented.

## Dependency direction

Per the frozen `ai/architecture/dependency-map.md`, this namespace depends on the constitution, the knowledge repository (structural integration). Dependencies flow only from the more operational namespaces toward the more foundational ones, never in reverse, so the graph has no cycles. These edges are pre-declared here and enforced by dependency-cruiser.

## Public API ownership (future)

When implemented in its future phase, this package will own the evolution contracts (change, compatibility, deprecation, migration, versioning of the layer). Until then it exports nothing.

## Explicit non-responsibilities

It owns no runtime behavior, no namespace service, and no business truth; it describes how the layer evolves, it does not execute it. It is an architectural reservation only; it is not an implemented package.
